Đang tải…

Thiếu Page? Bấm ＋ Thêm Page, đăng nhập Facebook và tick tất cả Page muốn dùng ở bước Facebook hỏi chọn Page.

💡 Khi nào cần bấm “Kết nối lại”?

  • Thanh trên cùng báo “Chưa kết nối” (màu đỏ).
  • Gần tới ngày ở ô “Quyền đọc dữ liệu đến” — Facebook bắt xác nhận lại khoảng 90 ngày một lần.
  • Bạn vừa đổi mật khẩu Facebook, hoặc bị gỡ quyền quản trị Page.

Bấm nút → đăng nhập Facebook → tick đủ mọi quyền và chọn đúng Page → xong. Tool tự lưu token mới.

🛠 Bấm “Kết nối lại” mà Facebook báo lỗi?

Nếu Facebook báo “URL bị chặn” hoặc nhắc tới redirect URI, vào trang quản lý app trên developers.facebook.com:

  1. App settings → Basic → ô App domains thêm localhost → Save.
  2. Facebook Login → Settings → ô Valid OAuth Redirect URIs thêm http://localhost:3000/auth/callback → Save.
✍️ Cách thủ công: dán token
  1. Mở Graph API Explorer, góc phải chọn đúng app của bạn.
  2. Bấm Permissions và tick:
    pages_show_list pages_messaging pages_read_engagement pages_read_user_content pages_manage_engagement pages_manage_metadata
